## About Me

Hi, I'm **Majid** — a Software Engineering student at **COMSATS University Islamabad, Wah Campus**, and the founder of **Cloudexify**, a software initiative focused on building useful digital experiences.

I believe the best way to learn software engineering is to build real things: understand the problem, design a solution, ship it, learn from what breaks, and improve it.

- **Building:** digital products and software solutions through [Cloudexify](https://cloudexify.site)
- **Exploring:** full-stack development, SaaS, AI-assisted workflows, and backend systems
- **Improving:** software architecture, database design, application security, and product quality
- **Location:** Pakistan 🇵🇰
